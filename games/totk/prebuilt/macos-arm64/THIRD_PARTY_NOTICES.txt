Evidence and scope
------------------
The repository build recipe publishes net10.0 for osx-arm64 with NativeAOT
and invariant globalization. The prebuilt README records .NET SDK 10.0.401.
The supplied executable contains the native runtime marker 10.0.12.
Official .NET release metadata maps SDK 10.0.401 to runtime 10.0.12
(release date 2026-09-08):
https://builds.dotnet.microsoft.com/dotnet/release-metadata/10.0/releases.json

The runtime and osx-arm64 NativeAOT compiler packages at 10.0.12 were
retrieved from NuGet. Their complete THIRD-PARTY-NOTICES.TXT files are
identical (SHA-256 66f1d4e44973185519bb4aa8a9718eb22fc7af2cc532e3ae9cfc4c127ee7fc54).
The runtime MIT license and complete third-party notices are reproduced
below, including notices for optional components that may be absent here.

Four direct NuGet pins were read from vendor/ryujinx/Directory.Packages.props
and Ryujinx.Common.csproj. The compatible net10.0 dependency groups were
followed recursively, including all 51 Humanizer locale dependencies.
The 72-package conservative graph below uses the declared minimum versions;
shared dependencies use the largest required minimum. NuGet metadata and
all available package license/notice files were retrieved for these exact
versions. The Humanizer and RecyclableMemoryStream licenses were also
retrieved from the repository commits recorded in their NuGet metadata;
MsgPack.Cli's Apache license was retrieved from its 1.0.1 release tag.

The original temporary restore/build directory, project.assets.json and
lock file are not retained by publish_native.sh, and no local .NET SDK or
original restore assets were available for this review. Therefore this is
a conservative attribution bundle, not a recovered original lock file or
proof of which assemblies survived NativeAOT trimming. In particular, the
legacy System.* NuGet license texts below describe possible restore/build
inputs; their inclusion does not assert that those old DLLs are embedded
in this executable instead of the .NET 10 framework implementations.
No unverified dependency is relabeled MIT by the top-level project license.

This file supplies the complete retrieved notices for the identified
runtime, source components, and conservative package graph. Keep it with
the unchanged executable and retain the surrounding project/upstream
licenses. A new executable or changed package pins require refreshing
this evidence and the source exporter's binary hash. This review does not
establish copyright provenance of unrelated source or grant Nintendo rights.
