# Super Smash Bros. Ultimate native Mac ports

One folder per game version; each carries its own runtime, graphics layer and scripts, and is built with the steps in
its README.

| Folder | Version | What it adds |
|---|---|---|
| [`13.0.2`](13.0.2/README.md) | 13.0.2 | offline: fights, World of Light, DLC, photos, 1080p or 2K, MetalFX |
| [`13.0.5_online`](13.0.5_online/README.md) | 13.0.5, the final update | online play through [ssbu-oof](https://github.com/FeReuss/ssbu-oof) servers: Quickplay, Battle Arenas, friends, Shared Content; a launcher for servers and accounts |

Players online must use the same game version: ssbu-oof servers and their port standard target 13.0.5.
