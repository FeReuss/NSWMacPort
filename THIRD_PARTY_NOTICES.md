For iOS, the build fetches Opus v1.6.1 and libvpx v1.16.0 from upstream and links them statically; their BSD notices still apply. SPIRV-Cross and hactool are fetched at the commits above, with their license files kept in the private work folder. Preserve Apache LICENSE/NOTICE files where supplied, and the libopus/libvpx copyright notices when distributing binaries that contain them. Apple SDKs and frameworks are build/system dependencies, not files copied into the source release.

The supplied NativeAOT translator is the only binary permitted by the source exporter's fixed SHA-256 allowlist and contains no bundled game shaders. Its SHA-256 is `6dd53d6486c96e3a95ae5fd49fdc35f75f6e603ff8ededa3d7250fd2e4fe1220`. The [accompanying notice bundle](games/totk/prebuilt/macos-arm64/THIRD_PARTY_NOTICES.txt) supplies 16 complete distinct license/notice texts, with source URLs and original-text and package SHA-256 checksums. Keep that file with this executable.

The review matched the binary's native runtime marker `10.0.12` to the README's SDK `10.0.401` through Microsoft's official release metadata. The .NET runtime and osx-arm64 NativeAOT packages at `10.0.12` were retrieved and their complete, identical third-party notice files and runtime MIT license preserved verbatim. The bundle also includes the Ryujinx, translator and Khronos notices, plus the exact direct pins from the current projects: Microsoft.IO.RecyclableMemoryStream `3.0.1` (MIT), MsgPack.Cli `1.0.1` (Apache-2.0), Humanizer `3.0.10` (MIT) and Gommon `2.8.1.2` (MIT). Compatible dependency groups were followed recursively to a conservative graph of 72 NuGet packages, including all 51 Humanizer locale packages. The complete available notices of the legacy `System.*` transitive packages are included without relabeling their Microsoft .NET Library terms as MIT.

`publish_native.sh` removes its temporary restore directory, so the original `project.assets.json`/lock file is unavailable. The graph records declared compatible minimum versions from the current source pins; it is not an exact recovered manifest of assemblies surviving NativeAOT trimming. The extra legacy-package notices cover possible restore/build inputs and do not assert those old DLLs are embedded instead of framework implementations. This identifies the evidence and its limit without claiming legal certification. Rebuilding the translator or changing dependency pins requires refreshing the bundle and the exporter's reviewed SHA-256 pin; changing only its checksum sidecar is insufficient.

An unused `Ryujinx.Common/Utilities/HexUtils.cs` in the original vendored subset identified Pascal Ganaye's CodeProject Open License code. That utility was removed from the distributed source after checking that the subset had no callers; it is not represented as MIT or GPL code here. Other upstream notices remain intact.

The source export excludes local games, keys, firmware fonts, extracted/rewritten images, generated game-shader caches, test directories and build output. It retains third-party source and these notices; excluded tests remain in the repository. The export does not publish an archive or audit the legal provenance of arbitrary new source files. Compatibility hashes, identifiers and public signature-verification keys are not secret decryption keys, and none of these metadata or source licenses grant rights to Nintendo's original files.
